# Topic backlog for the daily blog (SEO-led)

How to use this file (see CLAUDE.md for the full rules):
- Take the FIRST unused line under "Backlog". A topic is used if it is under "Done" or a file in `posts/` already covers the same question. Check `ls posts/` first; never repeat a topic, title or primary keyword.
- Line format: `Working title | primary search phrase | slug must contain | link to`.
  - The primary search phrase is what a reader would type into Google. Put it near the start of the title and in the first paragraph.
  - The post's file name (slug) must contain the fragment shown, so the build links it to the right practice-area page automatically.
  - "link to" is the practice-area page the article must link to in its body, written as a clean path such as `/section-17-drt-application`. Also link to one or two EARLIER articles from `posts/`.
- After publishing, move the line to "Done" and add the date.
- If fewer than 10 unused topics remain, add 20 new ones in the same format in the same commit. Choose questions real readers ask, with distinct primary phrases, and only topics where well-settled points can be stated.
- Where a topic involves an amount, threshold or period that changes, say "check the current notification" instead of giving a number.
